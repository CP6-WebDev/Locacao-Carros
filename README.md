# Marchas Importadas

Projeto desenvolvido em React para uma locadora de carros importados em São Paulo.

## Funcionalidades

- Página inicial com carros em destaque.
- Página com catálogo de veículos.
- Cards com informações dos carros.
- Navegação entre páginas.
- Layout responsivo.

## Tecnologias

- React
- Vite
- Tailwind CSS
- React Router
- JavaScript

## Como executar

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd locacao-carros
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```
